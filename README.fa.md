# مبانی پویایی امکان‌ها

این مخزن پیش‌نویسِ یک **کتاب علمی باز و در حال تکمیل** دربارهٔ امکان‌های دسترس‌پذیر، پیدایش و ازدست‌رفتن قابلیت‌ها و پیامدهای آن برای سازگاری سیستم‌هاست.

**نکتهٔ علمی:** «پویایی امکان‌ها» فعلاً نام یک *برنامهٔ پژوهشی پیشنهادی* است؛ نه نام یک علم تثبیت‌شده. تاکنون تنها چارچوب مفهومی، صورت‌بندی اولیه و یک مثال مصنوعی کوچک در اختیار داریم. هیچ قانون جهانی یا مزیت پیش‌بینی‌کنندگی مستقل اثبات نشده است.

متن اصلی کتاب به انگلیسی نوشته می‌شود تا ارزیابی و ارجاع علمی آسان‌تر باشد؛ ترجمهٔ فارسی باید از نظر اصطلاحات با نسخهٔ اصلی هماهنگ شود.
