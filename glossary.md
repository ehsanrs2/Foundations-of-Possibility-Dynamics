# Glossary (working)

| Term | Operational use in this book | Caution |
|---|---|---|
| Possibility | Candidate event/state consistent with a specified interpretation | Never used as one universal quantity |
| Operational reachability | Attainable within specified operations, time and budget | Not likelihood or value |
| Capability | Representable type of action, construction or function | Granularity can change a metric |
| Construction rule | Prerequisites and costs for producing a capability | May be an AND-hyperedge |
| Adjacent possible | Established research concept for possibilities enabled by novelties | Not invented here |
| Resilience | Performance preservation/recovery under specified disruptions | Requires an outcome and time scale |
| GOG | Candidate newly reachable goal count due to construction | Misses backup routes |
| GBR | Candidate count of baseline goals with dependency-disjoint constructible alternatives | Provisional, definition-sensitive |
| Ontic novelty | Change in what exists/is possible independent of observer | Philosophically contested |
| Epistemic novelty | Change in observer's knowledge or description | May mimic ontic novelty |
