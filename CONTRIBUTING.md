# Contribution and scientific review guidelines

This is a scientific manuscript under development, not a completed textbook.

1. Propose changes via branches and pull requests; no automatic merge of theoretical claims.
2. Mark paragraphs as **Prior work**, **Definition**, **Derivation**, **Hypothesis**, **Illustration**, or **Empirical evidence** where ambiguity exists.
3. For each new empirical result, include exact code commit, inputs, environments, random seeds, statistical protocol and negative cases.
4. For every purportedly new theorem, provide assumptions, proof, edge cases and relationship to known theorems.
5. For references, verify primary-source metadata and avoid copying copyrighted tables, figures or passages.
6. Require at least one counterexample or boundary condition for all broad claims.
7. Separate English canonical prose from Persian translation until terminology is reviewed.
8. Citation/licensing/author-credit decisions must be made explicitly before the first public release.

Suggested PR checklist: scientific claim status; baseline comparison; citation provenance; math consistency; reproduction instructions; no unsupported superlatives.
